For the assignment I used Claude, Claude Code, ChatGPT and Codex:

- Claude and ChatGPT for the design (HLD, LLD).
- Claude Code for development, and Codex for reviewing and criticizing.

Examples of things I rejected:

- Data model design - I wanted a much simpler model.
- Logical decisions - How to treat abstentions (A).
- Minimal API - I like working with a controller per feature, and it is easier to migrate to a Function App in the future.
- Use of `var` and unnecessary class types.
- Jobs parsing files one at a time.
